# Annual Architecture Review

| Field | Value |
|-------|-------|
| **Program** | ARCHITECTURE-GOVERNANCE-OPERATIONS-1 |
| **Type** | Architecture Ops |
| **Date** | 2026-07-27 |

## Purpose

Yearly enterprise review of architecture health and governance — not a redesign forum by default.

## Cadence

Once per calendar year (Architecture Authority schedules). Mid-year mini-review optional.

## Agenda (mandatory topics)

| Topic | Inputs |
|-------|--------|
| Domains | Domain Authority Matrix · CD-01 |
| Ownership | ADRs · write owners · dual-layer clarifications |
| Dependencies | Cross-Domain Dependency Matrix · CD-02 |
| Constitutions | Constitution Registry · CV lifecycle · Pending backlog |
| ADRs | Registry aging · Superseded · gaps |
| Enterprise Governance | This Ops framework effectiveness · CD-03…06 |
| Platform maturity | Order / Settlement / Reporting / Register / Session / Kitchen / Menu / Device / Waiter |
| Architecture risks | Debt register · exceptions · audit findings |
| Strategic roadmap | Next authorized programs · GOV-16 stability check |

## Outputs

1. Annual Architecture Review Report  
2. Updated risk / debt priorities  
3. Adoption decisions for Pending constitutions (or explicit deferrals with dates)  
4. Roadmap adjustments (programs, not silent constitution inflation)  
5. Metrics target updates  

## Participants

Architecture Authority · ARB · Domain Architects · TDA · Platform Governance Lead · invited Program Owners.

## Rule

Annual Review may **recommend** constitution/ADR changes; it does not bypass CV-03 / ADR Ops for breaking changes.
