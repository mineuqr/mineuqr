# Program Certification

> **Constitution §28** · [Compliance](../constitution/Compliance.md)

## Certification outcomes

| Outcome | Meaning |
|---|---|
| **Certified** | Full compliance with Constitution and in-scope ADRs |
| **Conditionally Certified** | Known gaps with dated remediation ADR |
| **Not Certified** | Program completion milestone blocked |

## Evidence package

1. Completed [Architecture Traceability Matrix](../templates/Architecture-Traceability-Matrix.md)
2. Fitness function CI results
3. Architecture review sign-off
4. Updated [ADR Registry](../constitution/ADR-Registry.md) implementation status

## Rule

*Implementation cannot be certified until compliance is verified.*
