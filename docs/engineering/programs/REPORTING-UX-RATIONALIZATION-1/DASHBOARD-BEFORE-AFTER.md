# Dashboard Before / After Summary

| Area | Before | After |
|------|--------|-------|
| Period control | Buried in Order Sales cards | Top-of-page scope (calendar month/year) shared by all sections |
| Overview KPIs | Lifetime `getBusinessMetricsSummary` (no from/to) | Bound to active Gregorian period |
| Catalog Overview | First viewport | Removed from Reports hierarchy |
| Executive | Absent on live dashboard | Exec V2 strip (Gross/Net/Refund/Tax/Orders/Averages) |
| Refund | Net only on Overview; rest Excel-only | Unified Refund Analytics section |
| Payment | Month-scoped only | Bound to active period; refund mix in Refund section |
| Trends | Unscoped | Bound to active period |
| Terminology | Check Revenue / Net Revenue / Refund Publications | Gross Sales / Net Sales / Refund Amount |
| Today Order Sales | Mixed with period cards | Explicitly labeled **(Business Day)** |
