# PUBLIC RENDERING PRESERVATION

Disablement is entitlement, not deletion.

| Surface | When capability OFF |
|---------|---------------------|
| Public menu (`category.listPublic`, `menuItem.listByRestaurant`, `offer.listActive`) | Continues |
| Stored design (template / colors / fonts / images) | Preserved and rendered |
| Public QR / `table.getByNumber` | Continues |
| Guest session GET | Continues |
| Existing tables / QR identities | Preserved |

FROZEN may still suspend public menu/order independently.
