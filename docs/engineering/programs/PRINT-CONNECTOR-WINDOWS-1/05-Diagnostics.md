# PRINT-CONNECTOR-WINDOWS-1 — Diagnostics

---

## WindowsRuntimeDiagnostics

`WindowsRuntimeDiagnostics.snapshot(restaurantId, connectorHealth)`:

- Installed printers (live discovery)
- Selected printer
- Default printer name
- Host process platform
- `RLC_RUNTIME` flag
- Connector health snapshot

---

## LocalConnectorDiagnostics

General RLC diagnostics (identity, config, session, health) — unchanged from PRINT-CONNECTOR-LOCAL-1.

---

## No Business Diagnostics

Diagnostics report infrastructure state only — no orders, jobs, or workflow data.
