# Monthly Dashboard

## Question

**How is the restaurant doing this month?**

## Scope

Selected Gregorian calendar month via Business Day–aware `monthReportingRange`.

## Experience contract

**Identical** to Today:

- Same six cards  
- Same order  
- Same colors  
- Same interactions  
- Same typography  

Only the period and title/subtitle change.

## Success criterion

**Zero relearning** when switching from Today → This Month.
