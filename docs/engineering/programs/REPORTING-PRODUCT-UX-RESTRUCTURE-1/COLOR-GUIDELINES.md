# Color Guidelines

## Category palette (dark executive shells)

| Category | Family | Border / accent intent |
|----------|--------|------------------------|
| Cash | Green / Emerald | Tender cash recognition |
| Card | Blue / Sky | Electronic payments |
| Refund | Red / Rose | Loss / reversal attention |
| Tax | Purple / Violet | Fiscal collection |
| Orders | Orange | Operational volume |
| Net Sales | Teal / Emerald success | Outcome |

## Rules

1. One category → one family (no rainbow inside a single card)  
2. Avoid monochrome single-accent dashboards  
3. Avoid purple-on-white default AI clichés for the overall chrome (shells stay slate + category tint)  
4. Maintain WCAG-minded contrast for labels (`slate-400`) vs values (tinted lights)  
5. Gradients are subtle vertical washes — not neon glows  

## Recognition test

With labels removed, category color alone should still hint Cash vs Refund vs Tax.
