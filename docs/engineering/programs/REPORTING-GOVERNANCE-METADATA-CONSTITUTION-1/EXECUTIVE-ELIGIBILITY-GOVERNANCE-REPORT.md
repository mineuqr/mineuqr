## Rule summary

```
Presentation Scope includes Executive (Scope 1)
        +
Promotion Pipeline complete (KPI-09 → Stage 6)
        +
Classification Class 1 (or Widget under Executive protection)
        =
Executive Dashboard eligibility
```

Scope alone = **necessary, not sufficient**.

## Decision matrix

| Has Scope E? | Promotion Stage 6? | Class 1 (or governed widget)? | Appear on Executive Dashboard? |

| No | — | — | **No** |
| Yes | No | — | **No** (GOV-01) |
| Yes | Yes | No (e.g. still Class 4) | **No** — reclassify required |
| Yes | Yes | Yes | **Yes** |
