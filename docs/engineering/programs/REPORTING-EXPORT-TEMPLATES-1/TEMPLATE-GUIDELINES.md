# REPORTING-EXPORT-TEMPLATES-1 — Template Guidelines

**Audience:** Presentation engineers maintaining Excel/PDF export templates.

---

## 1. Non-negotiables

1. Every numeric KPI must come from a Reporting DTO field already present on the bundle.  
2. Never call `order.list`, `ops.getSettlement*`, or live Business Settings for KPIs.  
3. Never add `.reduce` / SUM / averages that invent business totals.  
4. Revenue and Order Sales must remain visually and verbally distinct.  
5. Catalog advanced metrics (top sellers) stay as informational placeholders until REPORTING-CATALOG-METRICS-1.

---

## 2. Branding checklist

- [ ] Restaurant name from bundle  
- [ ] Logo optional (`logoUrl`) — failure must not block export  
- [ ] Report title localized  
- [ ] Period + generated timestamp  
- [ ] Currency + pricing mode + tax policy from Check snapshots on Business Metrics DTO  
- [ ] Footer: Generated by MineuQR + page numbers (PDF) / header-footer (Excel)

---

## 3. Excel guidelines

- Cover sheet first  
- Frozen header rows on data sheets  
- Alternating row colors + professional borders  
- Currency `numFmt` on money columns  
- Auto-ish column widths from content  
- Landscape for trend / rollup sheets  
- Print titles + fit-to-width  
- Chart images optional (Canvas); tables always present  

---

## 4. PDF guidelines

- Cover meta block before sections  
- Section titles + horizontal rules  
- Print-ready tables with zebra rows  
- Static bar charts when series exist  
- Page numbers + “Generated by MineuQR” footer on every page  
- Helvetica Latin-1: Arabic labels fall back to English for glyph reliability; Excel remains the Arabic-primary surface  

---

## 5. Localization

| Concern | Excel | PDF |
|---------|-------|-----|
| RTL sheet view | `rightToLeft` when `language === "ar"` | LTR text operators (font limit) |
| Labels | Localized AR/EN | English-safe operators |
| Digits | **Western 0-9 always** (`toWesternDigits` / `numberingSystem: latn`) | Same |
| Dates | Localized labels + Western digits | Localized + Western digits |
| Currency | Snapshot symbol/code + Western amount digits | Same |

### Official digit policy

Arabic labels remain Arabic. All numeric values (money, counts, percentages, dates, tables, charts) use Western digits only — never Eastern Arabic digits (`١٥٬٤٥٠٫٧٥`).

---

## 6. Consistency test

For the same restaurant + period:

1. Note Dashboard KPI card strings from `reporting.*`  
2. Export Excel + PDF  
3. Confirm identical Revenue, Order Sales, Paid Checks, averages, Sessions, Orders
