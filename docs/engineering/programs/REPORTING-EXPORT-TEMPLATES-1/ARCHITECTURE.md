# REPORTING-EXPORT-TEMPLATES-1 — Architecture

**Classification:** Reporting Presentation Architecture  
**Status:** Approved for implementation → PRODUCTION CERTIFIED target  
**Date:** 2026-07-16  
**Depends on:** REPORTING-EXPORTS-1 (PRODUCTION CERTIFIED)  
**Does not modify:** Reporting Platform, Reporting DTOs, Order, Check, Session, Runtime, API contracts, Business Settings  

---

## 1. Objective

Transform MineuQR Excel/PDF exports into enterprise-quality, executive-ready business documents.

Presentation layer only:

- branding  
- layout  
- typography  
- charts (visualizing Reporting DTO series)  
- print readiness  
- RTL / LTR formatting  

No KPI calculations. No reporting logic.

---

## 2. Boundary

```
reporting.* DTOs  (unchanged)
        ↓
RestaurantReportingExportBundle  (presentation assembly)
        ↓
Enterprise Excel Template · Enterprise PDF Template
```

Dashboard, Excel, and PDF remain numerically identical because they render the same DTO fields.

---

## 3. Document structure

| Sheet / Section | Purpose |
|-----------------|---------|
| Cover | Restaurant logo/name, title, period, generated time, currency, pricing mode, tax policy |
| Executive Summary | KPI card layout |
| Financial Summary | Revenue vs Order Sales distinction + tax / complimentary / voided |
| Operational Summary | Live operational KPIs |
| Catalog | Available catalog stats + placeholder for REPORTING-CATALOG-METRICS-1 |
| Revenue Trend | Table + chart from Business Metrics Trend DTO |
| Order Sales | Table + chart from Order Sales Rollup DTO |

---

## 4. Branding rules

- Restaurant identity comes from the export bundle (`restaurantName`, `logoUrl`)  
- No hardcoded restaurant branding  
- Platform footer: “Generated by MineuQR”  

---

## 5. Charts

Charts consume Reporting DTO series only.

- Excel: optional Canvas PNG chart images embedded when Canvas is available  
- PDF: static bar charts drawn from the same DTO values  

Presentation scaling (axis max) is layout-only — not KPI authority.
