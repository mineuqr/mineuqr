# FULL-PLATFORM.md

FULL_PLATFORM means all **current** commercial capabilities in `FEATURE_KEYS` (Projection ∪ Legacy Compat).

There is no static owner capability matrix. When a new capability is added to the runtime vocabulary, FULL_PLATFORM receives it automatically.

Commercial limits are unrestricted (`null` / unlimited quota). Platform safety controls remain enforced:

- authentication
- authorization
- rate limiting
- infrastructure and integrity safeguards
- destructive-operation guards

FULL_PLATFORM is not “disable all safeguards”.
