## Before (legacy experience)

| Surface | Pattern | Problem |
|---------|---------|---------|
| Plan Wizard step 4 | Flat 2-column checkbox grid (`max-h-48`) | Settings-like; no domain; no description; no filter metaphor |
| Feature Bundle create dialog | Same checkbox grid | Duplicate unstructured presentation |
| Pricing preview | Flat ✓ list (slice 8) | Incomplete; not grouped; weak public-page parity |
