# AUDIT — LANDING-PAGE-EXPERIENCE-1

**Date:** 2026-07-28  
**Scope:** Public landing page (`/`) only

## Pre-change assessment

### Strengths
- Existing MineuQR visual system (`landing-page`, `landing-card`, teal accents) was coherent.
- Hero already stated Restaurant OS positioning.
- Framer Motion was already in use (no new animation library needed).
- SEO meta helper and footer trust links existed from prior programs.

### Weaknesses
1. **Hero density** — Stat cards competed with the headline and product preview in the first viewport.
2. **Flat feature wall** — Eleven equal cards diluted hierarchy; visitors could not prioritize the OS story.
3. **Weak storytelling** — No Menu → Ordering → Kitchen → Payments → Analytics → Management → Growth journey.
4. **How-it-works lag** — Three menu-centric steps; outdated vs production OS scope.
5. **Preview fidelity** — Hero mock was thin and did not show ordering channels / kitchen / payments.
6. **CTA secondary** — “View Plans” jumped to pricing before visitors understood the product; explore-in-page was missing.
7. **Motion a11y** — Animations did not systematically respect `prefers-reduced-motion`.
8. **Nav** — No in-page anchors to journey/capabilities.

### Constraints honored
No rebrand, no palette change, no site-wide redesign, no fabricated testimonials/stats, no heavy animation libraries.
