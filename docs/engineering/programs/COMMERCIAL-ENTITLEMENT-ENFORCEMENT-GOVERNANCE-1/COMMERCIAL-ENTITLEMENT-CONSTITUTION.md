# COMMERCIAL-ENTITLEMENT-CONSTITUTION.md

Normative SSOT: [Commercial Entitlement Enforcement Constitution v1.0](../../../architecture/constitution/Commercial-Entitlement-Enforcement-Constitution-v1.0.md).

This program adopts CE-01 through CE-30 without modification.

## Lesson converted to law

Forensics proved the Live Plan resolver was correct. Repair proved operational mutations could skip `requireFeature`. Governance now requires every future commercial capability to complete definition → composition → resolution → **server enforcement** → UI → negative tests before certification.
