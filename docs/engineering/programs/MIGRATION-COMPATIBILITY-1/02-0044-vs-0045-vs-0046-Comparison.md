- One `tx.execute()` sends all 7 statements → **fails on TiDB**

## Why Print Migrations Succeeded Despite "No Print Tables Now"

- `0030_print_infrastructure` was applied successfully — it uses `--> statement-breakpoint` between each DDL (12 parts)
- `0043_print_purification` dropped print tables — also breakpoint-separated (12 parts)
- Current absence of print tables is **post-0043 state**, not evidence that multi-statement files work without breakpoints

## Conclusion

0044 and 0045 succeed because each file contains **exactly one SQL statement per drizzle `execute()` call**.

0046 fails because it contains **seven SQL statements in one drizzle `execute()` call** without statement breakpoints.
