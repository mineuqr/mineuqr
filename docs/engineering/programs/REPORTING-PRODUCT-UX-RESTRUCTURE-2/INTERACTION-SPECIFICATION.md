# Interaction Specification

| Affordance | Spec |
|------------|------|
| Hover | Soft lift + scale + category glow (`motion-safe`) |
| Press | Scale down + radial ripple at pointer |
| Focus | Visible cyan ring + offset |
| Keyboard | Enter / Space activate drill |
| Touch | `min-h` ≥ ~7.5rem cards; tabs `min-h-10` |
| Reduced motion | Transitions gated by `motion-safe:` |

No continuous pulse / flash.
