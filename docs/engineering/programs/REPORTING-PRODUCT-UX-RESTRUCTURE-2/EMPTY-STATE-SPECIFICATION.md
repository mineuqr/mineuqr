# Empty State Specification

## Rule

Never present a dashboard of only zeros when the period has no activity.

## Trigger

`isExecutivePeriodEmpty` after period queries finish: no orders, no revenue/net/refund/tax, no tender totals.

## Experience

- Soft gradient shell  
- Utensils illustration mark  
- Friendly title + helpful next step copy  
- Distinct Today vs Month messaging  

## Forbidden

- Six cards showing `0.00` / `0` as the primary empty experience  
- Technical error language for “no sales yet”
