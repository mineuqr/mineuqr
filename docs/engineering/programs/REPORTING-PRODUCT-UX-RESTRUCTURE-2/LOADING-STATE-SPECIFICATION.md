# Loading State Specification

## Period dashboards (Today / Month)

Use `ExecutivePeriodDashboardSkeleton` — six card-shaped placeholders matching final grid (including Net span).

## Financial Analytics

| Surface | Loading |
|---------|---------|
| Overview | Skeleton if month business still loading |
| Trends | Existing chart/insight skeletons |
| Payment / Refund | Existing KPI grid skeletons |

## Rules

- Maintain layout stability (no spinner-only collapse)  
- Prefer skeletons over centered spinners on executive surfaces  
- `aria-busy` on skeleton grids
