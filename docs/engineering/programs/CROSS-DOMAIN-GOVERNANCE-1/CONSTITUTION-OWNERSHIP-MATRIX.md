## Enterprise vs domain

| Constitution / Framework | Owning domain | Enterprise role |
|--------------------------|---------------|-----------------|
| Architecture Constitution | Enterprise (Architecture Authority) | Supreme architectural authority |
| Architecture Constitution Versioning Framework | Enterprise | Versions all constitutions |
| Constitution Registry | Enterprise | Index / lifecycle tracking |
| Enterprise Architecture Governance Framework (this) | Enterprise | Cross-domain coordination |
| Reporting UX / KPI / OBJ / GOV constitutions | **Reporting Platform** | Enterprise ensures non-conflict with Architecture & Financial Laws |
| Ordering Invariants | **Order Platform** | Enterprise upholds via Architecture Constitution |
| Financial Settlement / Refund / Custody ADRs (constitutionalized) | **Settlement Platform** (+ Check write owner) | Enterprise conflict resolution CD-04 |
| Register custody ADRs | **Register Platform** | Enterprise coordinates vs Settlement |
| Domain-specific future constitutions | Declaring domain | Must register (CD-06 / CV-06) |

## Rule

- Domain constitutions: authored and maintained by the domain’s Technical Design Authority under Architecture Authority adoption.  
- Enterprise Governance: coordinates, registers, resolves CD-04 conflicts — **does not rewrite domain formulas or aggregates**.
